PDF 轉 Markdown

點擊選擇 PDF，或把檔案拖進視窗
轉換選項（對應 CLI 旗標）
對等 CLI 指令： 
pdf2md <請先選擇 PDF>
需要 OCR：此 PDF 無可用文字層，請改用 OCR 流程。
Markdown 預覽：
尚未儲存：轉換後按「儲存 .md…」會寫到此位置

PDF 轉 Markdown 

    
把 PDF 轉成 Markdown 的 Windows 桌面軟體。底層是 Rust 製的
      pdf-inspector（純本機解析，文字型 PDF 免 OCR）。
      界面選項與 pdf2md CLI 旗標一一對應，轉換前會顯示對等指令。

    
    
      
  • 轉換核心：pdf-inspector（分類／擷取／Markdown）
    • 
      
  • 桌面殼層：Tauri 2（WebView2），本機靜態頁面
    • 
      
  • 檔案對話框：原生系統對話框
